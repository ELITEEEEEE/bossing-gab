BOSSING GAB — A LITTLE MIDNIGHT LOVE WEBSITE
Made for Bossing Gab, from Elet ♡

FILES
- index.html : page structure
- style.css  : midnight theme, layout, animations
- script.js  : slideshow, names, editable messages, secret, envelope

HOW TO USE
1. Extract this folder and open it in VS Code.
2. Put your pictures in a folder named "photos" in this same folder.
3. Name them memory-1.jpg, memory-2.jpg, memory-3.jpg, memory-4.jpg,
   OR edit the image paths in the slides array near the top of script.js.
   JPG, PNG, WEBP etc. are fine as long as the file extension/path matches.
4. Edit herName, yourName, slide titles/messages, secretMessage, and finalMessage
   near the top of script.js.
5. Double-click index.html to open it, or use VS Code Live Server.
6. To share it online, upload the files to a static host such as GitHub Pages or Netlify.
   Local file paths only work for photos included in the uploaded website folder.

NOTES
- The website uses no backend and does not collect or send any data.
- Google Fonts may need an internet connection; fallback fonts are included.
- Music is not included in this version.
